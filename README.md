# Heat Haze - ESPless version

This is a conversion of doodlum's [Heat Haze](https://www.nexusmods.com/newvegas/mods/76286) mod into an ESP-less version.

## Why?

I wanted an ESP-less version of this mod since i wanted to see how the effect was being triggered and working.

Plus i figured it could be super useful to configure it to make it a bit less... static

At this point, ESP-less + distance modifier is the goal

Original mod: doodlum's [Heat Haze](https://www.nexusmods.com/newvegas/mods/76286).
